Sobre esta Aplicação

1. Arquitetura MVT do Django

O Django segue o padrão Model — View — Template.

Diagrama (desenho em papel)

📸 Insere aqui a fotografia do teu desenho

Componentes

  • Model — define a estrutura dos dados e comunica com a base de dados via ORM.
  • View — recebe pedidos HTTP, processa dados e devolve uma resposta.
  • Template — ficheiros HTML que renderizam os dados dinamicamente.

Fluxo de informação

  • 1. Browser faz um pedido HTTP para um URL.
  • 2. O urls.py encaminha para a view correspondente.
  • 3. A view consulta ou modifica dados via Model.
  • 4. O Model comunica com a base de dados.
  • 5. A view passa os dados ao template, que gera o HTML.
  • 6. O HTML é devolvido ao browser.

models.py

class Licenciatura(models.Model):
    nome = models.CharField(max_length=100)
    duracao = models.IntegerField()
    creditos = models.IntegerField()
    informacao = models.CharField(max_length=250)

class Aluno(models.Model):
    nome = models.CharField(max_length=100)
    numero = models.DecimalField(max_digits=8, decimal_places=0)
    ano = models.IntegerField()
    licenciatura = models.ForeignKey(Licenciatura, on_delete=models.CASCADE)

class Professor(models.Model):
    nome = models.CharField(max_length=100)
    unidades_curriculares = models.ManyToManyField('UnidadeCurricular', blank=True)

class Tecnologia(models.Model):
    nome = models.CharField(max_length=100)
    tipo = models.CharField(max_length=150)
    descricao = models.CharField(max_length=200)
    site = models.URLField()
    interesse = models.IntegerField()

class Projeto(models.Model):
    titulo = models.CharField(max_length=100)
    descricao = models.CharField(max_length=200)
    data_de_realizacao = models.DateField()
    tecnologias = models.ManyToManyField(Tecnologia)
    link = models.URLField()

class TFC(models.Model):
    titulo = models.CharField(max_length=100)
    descricao = models.CharField(max_length=200)
    autor = models.ForeignKey(Aluno, on_delete=models.CASCADE)
    orientador = models.ForeignKey(Professor, on_delete=models.CASCADE)
    ano = models.IntegerField()
    tema = models.CharField(max_length=100)

class Competencia(models.Model):
    nome = models.CharField(max_length=100)
    tipo = models.CharField(max_length=100)
    nivel = models.IntegerField()
    experiencia = models.IntegerField()
    projetos = models.ManyToManyField(Projeto)

class Formacao(models.Model):
    titulo = models.CharField(max_length=100)
    tipo = models.CharField(max_length=100)
    instituicao = models.CharField(max_length=150)
    data_inicio = models.DateField()
    data_conclusao = models.DateField()
    descricao = models.CharField(max_length=200)
    aluno = models.ForeignKey(Aluno, on_delete=models.CASCADE)

class MakingOF(models.Model):
    tipo = models.CharField(max_length=100)
    descricao = models.CharField(max_length=200)
    justificacao = models.CharField(max_length=250)
    solucao = models.CharField(max_length=150)
    uso_ia = models.BooleanField()
    descricao_uso_ia = models.CharField(max_length=250)
